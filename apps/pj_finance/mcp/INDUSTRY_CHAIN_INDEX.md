# 产业链指数编制约定

## 默认口径

- 样本空间：指定 `app/industryLink/taxonomies/<id>.yaml` 中拥有合法 `ts_code` 映射的公司。
- 价格：前复权收盘价，基点为区间首个有效交易日，默认 1000 点。
- 默认权重：`chain_balanced`。每个“根泳道 / 子泳道”先获得相同预算，泳道内按
  `sqrt(流通市值) × 业务纯度` 分配，再执行单一成分 10% 上限。
- 备选权重：等权、流通市值、流通市值封顶、手工权重。
- 缺失行情：停牌期间以前值延续；基日无价格的公司不进入本次指数。
- 输出：一个 parquet 同时保存 `record_type=index` 的日度指数和
  `record_type=constituent` 的基日成分/权重。

该实现是研究指数，不是可直接对外发行的证券指数。正式发布还应补充上市时间、ST/退市、
流动性、可投资性、定期调样、临时调样和除数连续性规则。

## 公司级编辑字段

产业链 YAML 仍是公司归属的事实源。需要覆盖指数行为时，在公司 `info` 中增加以下标量字段：

```yaml
info:
  指数纳入: 是       # 否 / false / 0 时排除
  业务纯度: 0.8      # 0~1；默认 1
  指数权重: 0.05     # 仅 manual 权重法使用，可写 5% 或 0.05
```

编辑顺序建议：

1. 先确认公司确实属于该产业链及具体子泳道。
2. 再判断主营业务纯度，而不是仅凭概念关联。
3. 默认纳入；仅在业务关系弱、无法交易或证据不足时明确排除。
4. 手工权重只用于有明确方法论依据的指数，不作为默认配置。

## MCP 工具

- `industry_chain_index_preview(taxonomy_id)`：查看成分、缺失代码和覆盖字段。
- `industry_chain_index_build(...)`：拉取行情、计算指数并写入 parquet。
